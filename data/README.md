# Data

Dataset: job-postings-applications by mindweave
Source: https://huggingface.co/datasets/mindweave/job-postings-applications
License: CC BY-NC 4.0 (https://creativecommons.org/licenses/by-nc/4.0/)

The files in `raw/` are the original, unmodified CSV files.
All cleaning and transformations were done in Power BI (Power Query and DAX).

Files: applications, candidates, companies, interviews, jobs, offers
